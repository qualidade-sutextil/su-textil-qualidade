Inspeção de Costura (recebimento)

Registro padronizado da inspeção de lotes recebidos, com rastreabilidade, amostragem, resultado e evidências.

Como lançar: preencha os dados do romaneio uma vez, adicione cada tamanho (quantidade inspecionada, quantidade reprovada, problema e foto) e, quando terminar, clique em Finalizar romaneio para gerar um único relatório. O que você digitar fica salvo como rascunho, mesmo se fechar a página.
Critério de inspeção: registre o lote recebido, a quantidade inspecionada, as não conformidades encontradas e o resultado. A taxa de amostragem é calculada automaticamente quando possível. O registro deve permitir rastrear fornecedor/oficina, cliente, pedido, produto, problema e evidência.

Segurança, Backup e Manutenção


Controle administrativo e continuidade dos dados do sistema.



  

    
Senha do administrador

    
A senha protege inclusão, edição e exclusão de registros. Na primeira utilização, o sistema solicitará que você defina uma senha.

    

      

      

    

    

    
Observação: como este é um HTML local, a proteção é de aplicação no navegador, não de servidor. Para uso corporativo multiusuário, recomendo migrar futuramente para banco de dados + autenticação.

  

  

    
Backup e restauração

    
Faça backups periódicos. O arquivo JSON preserva inspeções, tecidos, RNCs, cadastros e configurações.

    

      
      
      
    

    
  





  
Boas práticas de continuidade

  
    
    
  • Baixe um backup antes de qualquer atualização importante do HTML.
    • 
    
  • Guarde os arquivos de backup fora do navegador, preferencialmente em uma pasta da empresa/OneDrive/Google Drive.
    • 
    
  • Ao abrir uma nova versão, use “Restaurar backup” para recuperar a base anterior.
    • 
    
  • Não limpe os dados do navegador sem antes exportar o backup.
    •
